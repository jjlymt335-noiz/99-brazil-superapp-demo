# 99 Brazil Super App Home Demo

A responsive, clickable written-test prototype for a 99 Brazil multi-service home page. Stable service shortcuts remain the primary navigation; ongoing tasks, owned benefits, and a single dismissible suggestion follow in that order.

## Public demos

- Portuguese: <https://jjlymt335-noiz.github.io/99-brazil-superapp-demo/>
- Chinese: <https://jjlymt335-noiz.github.io/99-brazil-superapp-demo/?lang=zh>

## Local development

```bash
npm install
npm run dev
```

Run unit and browser tests with `npm test` and `npm run test:e2e`.
